# Counter

## Project brief

In this challenge, you will build a simple counter: a number on screen with buttons that change it.

## Implementation requirements

- **Display:** Show the current count, starting at 0.
- **Increment and decrement:** One button adds 1 to the count and another subtracts 1.
- **Reset:** A button sets the count back to 0.
